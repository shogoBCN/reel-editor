# Angélica brief (human) vs engine brief

Angélica fills a **one-tab Excel** in her own words. Cursor turns it into `brief.yaml` and runs the pipelines. She does not edit YAML, `tipo`, `lado`, or filenames. She pastes photos at any pixel size and writes **grande / mediano / chico** in «Qué quieres»; compose fits the file into that box.

**Workbook she sees:** [plantilla_reel_angelica.xlsx](../../templates/angelica_brief/plantilla_reel_angelica.xlsx) — tabs Brief + Instrucciones. She marks **El reel empieza en** and **Terminas de hablar** on her original recording (`0:04`, `1:29,5`); she does not cut the file. Overlay columns `Desde`, `Hasta`, `Foto`, `Qué quieres`.

**Agent skill:** `.cursor/skills/angelica-reel-brief/SKILL.md` — import is a sketch; the agent amends YAML to the engine contract.

**Gold YAML:** [examples/ya_tienes/brief.yaml](../../examples/ya_tienes/brief.yaml)
