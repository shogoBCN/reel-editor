# Angélica brief (human format)

The reusable brief for Dra. Angélica is a **Google Sheet** (or the same tabs as CSV / xlsx). YAML is generated from it.

**Why a sheet:** timestamps, filenames, and left/right placement are tabular. A Google Doc is easier for pasted screenshots but is not parseable. Images stay in Drive / WhatsApp with filenames that match the `archivo_imagen` column.

**Template:** [templates/angelica_brief/](../../templates/angelica_brief/README.md)

**Workbook:** [plantilla_reel_angelica.xlsx](../../templates/angelica_brief/plantilla_reel_angelica.xlsx) — File → Import into Google Sheets once, then duplicate per reel.

**Filled example:** [examples/ya_tienes/brief_sheet/](../../examples/ya_tienes/brief_sheet/)

Clock rule: every time is her **original recording**, including opening silence. `cortar_inicio` is subtracted later. See the template README for `tipo` / `lado` values and overlap rows (two stickers at once = two rows).
